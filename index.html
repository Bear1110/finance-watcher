怎麼看這一頁？
  • 我的錢一年大約賺幾 %？ → 累計年化報酬（XIRR），可以想成存款利率；正的就是整體有賺。
  • 實際賺了多少錢？ → 市值與損益走勢、報酬率下面的 NT$ 金額。
  • 股票本身表現好不好、有沒有贏大盤？ → 投資績效的 %、月報酬。它只看持股本身的漲跌（含股利、匯率），不受你什麼時候加碼影響。

% 和金額對不上通常是時機：大筆錢在下跌前才進場，股票本身可能還是漲的（% 為正），你的錢卻是虧的（金額為負）。

記錄股利

股利是現金收入，不會併入收支紀錄，避免重複計算。

依你的買賣紀錄與 Yahoo 的除息資料估算。日期為除息日（實際入帳通常晚數週，匯入後可編輯）；美股預扣 30%、台股單筆 ≥ NT$20,000 扣 2.11% 補充保費皆為估計，請對照券商入帳金額。

若某檔的持股數明顯偏高，通常是「匯入持倉」的買入日期不是實際買進日，可到交易紀錄修正日期，或在這裡設起算日。

下載備份／匯出

把勾選的資料存成一個 JSON 檔。全選就是完整備份；只勾一部分可以單獨匯出（例如只有收支）。清除或大量匯入前建議先下載完整備份。

匯入備份

選擇本網站匯出的 JSON 檔，可以挑要匯入哪幾類；匯入的類別會取代目前那一類的資料，沒勾的不受影響。
